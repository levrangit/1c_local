# ВставитьШтампЭксель_1.0

Внешняя обработка 1С для добавления штампа в книгу Excel (.xlsx).

## Шаблон штампа

Используется отдельная книга Excel (.xlsx), содержащая фигуру (Shape) с точным именем `Акк_Штамп`. В текст фигуры должны быть включены заполнители `Подразделение` и `ФИО_Инициатор`.

Обработка заменяет заполнители, затем копирует фигуру в целевую книгу на каждый лист с данными и располагает её в нижней левой части используемого диапазона. Результат сохраняется в отдельный файл с суффиксом `Штамп.xlsx`; исходная книга не перезаписывается.

## Требования и ограничения первой версии

- Windows-клиент 1С с установленным Microsoft Excel и доступным COM Automation.
- Входные и выходные файлы — `.xlsx`.
- Штамп добавляется на каждый лист с данными, а не на каждую физическую страницу печати. Для точного размещения на каждой распечатанной странице потребуется отдельная логика по горизонтальным/вертикальным разрывам страниц и настройкам печати.
- Не проверено запуском в конфигураторе 1С; перед использованием на рабочих книгах требуется тестирование на копиях.

## Структура

- `ВставитьШтампЭксель.xml` — описание внешней обработки.
- `ВставитьШтампЭксель/Ext/ObjectModule.bsl` — модуль объекта.
- `ВставитьШтампЭксель/Forms/Форма.xml` — описание основной формы.
- `ВставитьШтампЭксель/Forms/Форма/Ext/Form.xml` — описание реквизитов формы и событий.
- `ВставитьШтампЭксель/Forms/Форма/Ext/Form/Module.bsl` — логика формы и COM-обработка книги.
